# Prisma com SQLite

Projeto de estudo com Prisma ORM 7, SQLite e uma relacao de um-para-muitos entre `User` e `Post`.

## Comandos

```bash
npm install
npm run prisma:migrate -- --name nome_da_migration
npm run prisma:generate
npm run prisma:studio
npm run dev
```

Copie `.env.example` para `.env` caso o arquivo de ambiente ainda nao exista.
